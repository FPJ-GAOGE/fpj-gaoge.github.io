# University seals

- `sjtu.png`: Shanghai Jiao Tong University, standard red seal. [University visual-identity reference](https://vi.sjtu.edu.cn/index.php/articles/bulletin/13). [Source collection](https://github.com/weijianwen/SJTU-logo-banner), [unmodified original PNG](https://raw.githubusercontent.com/weijianwen/SJTU-logo-banner/master/SJTU_LOGO/PNG/sjtulogored.png). The collection traces the original artwork to SJTU's campus website.
- `xjtu.png`: Xi'an Jiaotong University seal. [University visual-identity reference](https://vi.xjtu.edu.cn/jcbf/xhgf.htm). [Source file page](https://en.wikipedia.org/wiki/File:Xi%27an_Jiaotong_University.png), [unmodified original PNG](https://upload.wikimedia.org/wikipedia/en/3/3d/Xi%27an_Jiaotong_University.png).

University names and marks belong to their respective institutions and are used to identify educational affiliations.
